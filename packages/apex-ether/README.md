# @jvsysarch/apex-ether

Biblioteca React reutilizable del sistema Apex Ether.

```tsx
import { ApexEtherPanel, ApexEtherMetric } from '@jvsysarch/apex-ether';
import '@jvsysarch/apex-ether/styles.css';
```

La biblioteca no depende de Apex Drive ni de Apex Ether Studio. Sus consumidores proporcionan telemetría mediante las propiedades y contratos exportados por el paquete.
