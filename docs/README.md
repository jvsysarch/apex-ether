# Documentación de Apex Ether

Esta documentación acompaña la versión inicial del sistema y explica tanto sus decisiones de producto como su integración técnica.

## Recorridos recomendados

### Para producto y diseño

1. [Motivación](motivation.md): por qué existe, qué problema resuelve y cuáles son sus principios.
2. Abrir el Studio en `/` para recorrer el catálogo.
3. Abrir `/lab` para revisar tokens, tipografía, color y superficie.

### Para integración

1. [Integración](integration.md): contratos, proveedor y ejemplos React.
2. [Arquitectura](architecture.md): fronteras, flujo de datos y rendimiento.
3. [Paquete](../packages/apex-ether/README.md): API inicial disponible.

## Estado

Apex Ether se encuentra en una etapa inicial. La API puede evolucionar antes de la primera versión estable; toda integración debe fijar una versión concreta y evitar importar archivos internos del paquete.
